# Индивидуальные баллы

## Определение

**Индивидуальные баллы (ИБ)** — баллы за игровые действия, которые можно однозначно отнести к конкретному Роботу Команды. ИБ используются для расчёта среднего индивидуального результата и рейтингового места РИБ в составе направления «Игры роботов» абсолютного рейтинга. **Не заменяют официальный счёт Союза в Матче.**

Формула средних баллов: СИБ = (ИБ₁ + ИБ₂ + … + ИБₙ) / n, где n — количество официальных матчей. Тренировочные матчи и матчи вне зачёта не учитываются. Если Робот не набрал ИБ — матч со значением ИБ = 0.

**НЕ включаются в ИБ:** игровые шары цвета Союза внутри Башни, белые шары, захват Маяка противника, общие бонусы Союза, Штрафы и любые достижения, которые невозможно отнести к одному Роботу.

## Баллы по периодам

### Автономный период

| Достижение | Баллы |
|------------|-------|
| Парковка в Зоне парковки согласно Рандомизации | 15 |
| Парковка в Зоне парковки не по Рандомизации | 10 |
| Парковка в зоне Склада | 5 |
| Сбивание Пластины Игровым шаром — нижний уровень | 10 (штраф) |
| Сбивание Пластины Игровым шаром — верхний уровень | 20 (штраф) |
| Установка Флага своей Команды на Верхней перекладине Союза | 20 (штраф) |
| Установка Флага своей Команды на Жёлтой перекладине | 40 (штраф) |
| Парковка на Башне: касается покрытия и Наклонной плоскости | 5 (штраф) |
| Парковка на Башне: не касается покрытия, касается Наклонной плоскости | 40 (штраф) |
| Парковка на Башне: удерживается без касания | 60 (штраф) |

> *Примечание:* В данном разделе регламента данные баллы указаны для демонстрации структуры; фактическое распределение может требовать уточнения по Приложению В.

### Заключительный период

| Достижение | Баллы |
|------------|-------|
| Парковка в Зоне Склада | 5 |
| Парковка на Башне — касается покрытия и Наклонной плоскости | 5 |
| Парковка на Башне — не касается покрытия, касается Наклонной плоскости | 40 |
| Парковка на Башне — удерживается без касаний | 60 |

### Управляемый период

В текущем сезоне отдельные действия для расчёта ИБ в Управляемом периоде (кроме Заключительного) не выделяются.
