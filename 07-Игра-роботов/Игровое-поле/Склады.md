# Склады

## Определение

**Склад** — зона на Игровом поле для хранения Игровых элементов и парковки Роботов. На поле два Склада в противоположных углах.

## Исходное расположение элементов

| Элемент | Количество на складе |
|---------|---------------------|
| Белые шары | 8 |
| Синие шары | 5 |
| Красные шары | 5 |

## Парковка в Складе

| Период | Баллы/робот |
|--------|-------------|
| Автономный период | 5 баллов |
| Заключительный период | 5 баллов |

## Доставка из Склада (ПС 9–10)

| Правило | Описание |
|---------|----------|
| **ПС 9** | Робот должен полностью покинуть Зону Склада, чтобы доставить элемент в Зачётную зону. Нарушение → Штраф + элемент не засчитывается. |
| **Выброс шаров** | Запрещено намеренно выбрасывать шары за пределы Склада. Непреднамеренное выкатывание при манёврах — не нарушение. Умышленный выброс → Штраф за каждый шар. |

## Особенность контроля (ПС 3 исключение)

Робот может Контролировать/Владеть **любым количеством** Игровых шаров, полностью находясь внутри зоны Склада. Это единственное исключение из лимита 2 шаров.
