# Размеры и разметка игрового поля

## Габариты

| Параметр | Значение |
|----------|----------|
| **Площадь поля** | 3,6 м × 3,6 м (12,96 м²) |
| **Борт по периметру** | Высота 30 см |
| **Покрытие** | Мягкие плитки |
| **Координаты** | Строки A–F, столбцы 1–6 |

## Зоны на поле

### Зоны Союзов
Обозначены красным и синим цветом. Примыкают к Игровому полю — в этих зонах во время Матча находятся Операторы Команд.

### Зоны парковки
Каждый Союз имеет несколько Зон парковки (номера 1–4).
- Зоны 1–3 участвуют в Рандомизации
- Зона 4 используется для начального размещения Маяков

### Склады
Два Склада расположены в противоположных углах поля.

### Башня
Центральная конструкция с нижним и верхним уровнями, боковыми Наклонными плоскостями и перекладинами.

### Зона Полевого игрока
Область рядом с полем, где находится Полевой игрок Союза. Для каждого Союза своя зона.

### Переходные зоны
Зоны пешеходного перехода для каждого Союза между их Зоной Союза и Игровым полем.

### Зоны переключения светофора
Области для визуальных сигналов судей.

## Допуск размещения (ПИ 8)

Игровое поле и Игровые элементы имеют допуск **±2 см**. Команды должны учитывать это при проектировании Роботов.

## Разметка старта

| Союз | Стартовые клетки |
|------|------------------|
| Красный | A5/A3/A2 (левая сторона поля) |
| Синий | F5/F4/F2 (правая сторона поля) |

Роботы устанавливаются у бортов так, чтобы касаться борта.
