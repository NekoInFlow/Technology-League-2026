# Предварительная установка элементов

## До начала Матча

| Действие | Кто выполняет |
|----------|---------------|
| Установка Игрового поля | Полевые судьи (по рис. 2.1–2.3) |
| Закрепление Пластин Зажимами на верхнем/нижнем уровнях | Полевые судьи |
| Размещение Игровых шаров, Маяков и элементов в исходных позициях | Полевые судьи |

## Установка Роботов

| Параметр | Описание |
|----------|----------|
| **Позиция** | У бортов на противоположных сторонах поля, касаясь борта |
| **Красный Союз** | Плитки A5/A3/A2 (левая сторона) |
| **Синий Союз** | Плитки F5/F4/F2 (правая сторона) |
| **Предзагрузка каждого Робота** | Один белый шар + один цветной шар по цвету Союза + Флаг Союза |

## После сигнала об окончании установки

Команды операторов **не имеют права**:
- Касаться Роботов до окончания Автономного периода
- Вмешиваться в управление

**Исключения:**
- Нажатие Кнопки Запуска для автономной программы
- Отключение Робота по указанию Судьи в целях безопасности

## Рандомизация

Судьи проводят случайный выбор целевой Зоны парковки (1, 2 или 3) для каждого Союза. Зона парковки 4 не участвует в Рандомизации. Маркеры для Рандомизации устанавливаются на поле перед началом.
