# Заключительный период

## Общие правила

| Параметр | Значение |
|----------|----------|
| **Длительность** | Последние 30 секунд Управляемого периода |
| **Управление** | Операторы |
| **Новые действия** | Установка Флагов + парковка на Башне |

## Баллы Заключительного периода (в состоянии покоя на конец Матча)

### Установка Флагов Союза на перекладинах

| Перекладина | Баллы/флаг |
|-------------|-----------|
| Верхняя перекладина соответствующего Союза | 20 баллов |
| Жёлтая перекладина | 40 баллов |

### Парковка на Башне

| Уровень касания | Баллы/робот |
|-----------------|-------------|
| Касается покрытия поля + Наклонной плоскости | 5 баллов |
| Не касается покрытия, но касается Наклонной плоскости | 40 баллов |
| Удерживается на Башне (без касаний покрытия и наклонной плоскости) | 60 баллов |

### Парковка в зоне Склада
| Период | Баллы/робот |
|--------|-------------|
| Заключительный период | 5 баллов |

## Правила установки флагов (ПС 12)

| Правило | Описание |
|---------|----------|
| Только в Заключительном периоде | Баллы засчитываются только за установку в этот период |
| Только флага своего Союза | Установка чужого флага запрещена |
| Неподвижность на перекладине | Баллы начисляются только если флаг в состоянии покоя на перекладине на конец Матча |
| Нельзя снимать флаг противника | Робот не может снимать Флаги противостоящего Союза |
| Нельзя удерживать чужой флаг дольше необходимого | Нарушение → Штраф |

## Парковка на Башне (ПС 10)

| Правило | Описание |
|---------|----------|
| Контакт с Наклонной плоскостью | Разрешён для парковки |
| Только своя Наклонная плоскость | Робот может парковаться ТОЛЬКО на своей Наклонной плоскости |
| Препятствовать сопернику | Запрещено препятствовать парковке соперника |

Исключение из ПИ 26: контакт с Башней разрешён для парковки и установки флагов.
