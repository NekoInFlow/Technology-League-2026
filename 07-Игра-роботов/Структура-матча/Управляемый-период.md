# Управляемый период

## Общие правила

| Параметр | Значение |
|----------|----------|
| **Длительность** | 120 секунд (последние 30 сек — Заключительный период) |
| **Управление** | Операторы через Станцию Управления |
| **Подготовка** | 5 секунд + обратный отсчёт «3-2-1 СТАРТ» после Автономного периода |
| **Полевой игрок** | Может выкладывать шары в Зону парковки 1 при обмене маяка (ПС 7–8) |

## Баллы Управляемого периода (в состоянии покоя на конец Матча)

### Сбивание Пластины Игровым шаром
| Уровень | Баллы/шт |
|---------|----------|
| Нижний уровень | 10 баллов |
| Верхний уровень | 15 баллов |

### Белый Игровой шар в Боковой зоне Башни Союза
| Условие | Баллы/шар |
|---------|-----------|
| Шар полностью в Боковой зоне Башни | 5 баллов |

### Шары цвета Союза внутри Башни
| Уровень | Баллы/шт |
|---------|----------|
| Нижний уровень | 5 баллов |
| Верхний уровень | 10 баллов |

## Обмен Маяка (ПС 7)

За один Маяк своего Союза → 3 дополнительных Игровых шара цвета своего Союза.

## Ограничения Полевого игрока (ПС 8)

| Правило | Описание |
|---------|----------|
| Только обмен маяка | Выкладывать шары только для обмена |
| Один шар за раз | Не более одного выложенного шара одновременно |
| Робот не в Зоне 1 | Выкладывать только когда ни один робот Союза не в Зоне парковки 1 |
| Без передачи рукой | Не передавать элементы роботу напрямую |

Каждое нарушение → Штраф.

## Запреты

| Правило | Описание |
|---------|----------|
| **ПС 2** | Взаимодействие с Маяком противника запрещено |
| **ПС 3** | Лимит контроля — макс 2 шара одновременно (исключение: внутри Склада) |
| **ПС 5** | Нельзя обнулять баллы противника |
| **ПС 14** | Не сбивать Пластины корпусом; не заезжать в зоны Башни |
| **ПС 15** | Не касаться Башни корпусом |
| **ПИ 24** | Тренер не управляет Роботом |
