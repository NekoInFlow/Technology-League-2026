# Повторный допуск

## Когда требуется

| Ситуация | Требуется ли повторный допуск? |
|----------|-------------------------------|
| Значительные физические изменения робота | ✅ Да (ПД 3) |
| Изменения, улучшающие производительность или способности | ✅ Да (ПД 3) |
| Судья требует повторно пройти допуск | ✅ Да (ПД 1.2) |
| Незначительные конфигурационные перестановки между матчами | ❌ Нет (если робот соответствует требованиям) |

## Запрещённые действия

| Действие | Последствия |
|----------|-------------|
| Использование робота без допущенной конфигурации | Робот не допускается к матчу |
| Отказ от прохождения проверки | Дисквалификация команды с мероприятия |
| Значительные изменения после допуска без повторной проверки | Пункт ПД 1.1 — проверка обязательна |

## Проверка всех конфигураций

На Техническом допуске робот проверяется **во всех возможных стартовых конфигурациях** (ПД 5).

Всё оборудование, суммарно используемое для создания всех механизмов робота, не должно превышать ограничения по количеству двигателей/сервоприводов — даже если части используются не одновременно. Нельзя иметь запасную половину робота с подключёнными моторами.

## Между матчами

Только механизмы, заявленные во время проверки, можно добавлять, снимать или переконфигурировать между матчами. Изменённый робот должен всё ещё соответствовать всем требованиям к роботам.
