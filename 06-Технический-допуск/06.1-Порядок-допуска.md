# Порядок допуска

## Общий принцип

Каждый Робот должен получить **Технический допуск** для возможности участвовать в матчах. Проверка подтверждает соблюдение всех правил Лига Технологий.

## Правила допуска

| Правило | Описание |
|---------|----------|
| **ПД 1** | Допуск обязателен; при значительных изменениях после допуска — повторная проверка; отказ = дисквалификация |
| **ПД 2** | Тренировочные матчи — допуск не требуется (если разрешит Главный судья) |
| **ПД 3** | Физические изменения, улучшающие производительность → повторная проверка перед следующим матчем |
| **ПД 4** | Процесс заканчивается либо допуском, либо отказом. Запись Судьи = допуск получен |
| **ПД 5** | Все механизмы должны быть представлены во всех стартовых конфигурациях; суммарное число двигателей/сервоприводов не должно превышать ограничения |
| **ПД 6** | Тест колёс/гусениц на повреждение поля: 15 сек на полной мощности — если плитка повреждена, колеса запрещены |

## Самостоятельная проверка

Команде рекомендуется проверить робота по «Листу Требований» минимум за **неделю** до чемпионата. Официальный лист: https://ncrobo.ru/ligatechnology

## Процедура допуска

1. Робот представляется со всеми механизмами во всех стартовых конфигурациях
2. Проверка соответствия каждому пункту Листа Требований
3. Команда отмечает соответствие, Судья подтверждает
4. При отказе — робот не участвует в матче до исправления и повторной проверки
