# Порядок проведения чемпионата

## Структура соревновательного дня

1. **Регистрация команды** — сдача документов
2. **Технический допуск робота** — проверка соответствия правилам
3. **Собеседование с экспертами (I этап)** — защита перед группой экспертов
4. **Собрание операторов** — briefing с судьями
5. **Церемония открытия**
6. **Квалификационные матчи** — 5–6 зачётных Матчей
7. **Выбор Союзов** — формирование пар для плей-офф
8. **Матчи на выбывание** — полуфиналы и финалы
9. **Награждение и церемония закрытия**

### Для «Открытий» и «Исследований»

1. Регистрация
2. Защита проекта (5 мин + 5 мин вопросы)
3. Командное задание
4. Награждение

### Для «Решений» и «Технологий»

Дополнительно:
- Собеседование II этап (углублённая оценка для номинаций)
- Защита Дизайна робота (пробный заезд + собеседование)
- Протекция Инновационного проекта (14 минут)
