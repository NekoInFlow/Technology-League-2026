# Ключевые даты и этапы

## Возраст участников

Участники должны соответствовать верхней границе возрастного ограничения на **31 мая 2027 года**.

## Этапы сезона

| Этап | Формат | Описание |
|------|--------|----------|
| **Товарищеские встречи** | Очный | Неофициальные мероприятия для подготовки; не влияют на квоты |
| **Региональные отборы** | Очный / Дистанционный | Официальные чемпионаты для получения квоты на Национальный чемпионат |
| **Национальный чемпионат** | Очный, 3 дня | Заключительный этап в г. Красноярск |

## Даты мероприятий

| Мероприятие | Время проведения |
|-------------|------------------|
| Регистрация команд | На сайте ncrobo.ru |
| Соревновательный день — защиты | С 10:00 до 18:00 (по местному времени) |
| Соревнование «Решений» и «Технологий» | С 09:00 до 18:00 |
| Квота — крайняя дата возраста | **31 мая 2027** |

## Квалификационные матчи

- Команды участвуют в **5–6 зачётных квалификационных матчах**
- При нехватке для кратного 4 — проводятся **матчи вне зачёта** (не влияют на рейтинг)
- Тренировочные матчи — по предварительной записи в зоне тренировочных полей

## Дистанционный формат

| Параметр | Значение |
|----------|----------|
| Для кого | Регионы без достаточного количества команд |
| Поле | Половина официальной версии поля |
| Матчей | 6 квалификационных |
| Подсчёт очков | Судьи + команда |
| Собеседование | Видеоконференция или заранее записанное видео |
| Инженерная книга | Электронный вид |
