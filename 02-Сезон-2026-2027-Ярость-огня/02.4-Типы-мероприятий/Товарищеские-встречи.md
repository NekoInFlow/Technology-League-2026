# Типы мероприятий

В течение сезона команда может участвовать в мероприятиях трёх типов:

## 1. Товарищеская встреча

| Параметр | Значение |
|----------|----------|
| **Статус** | Неофициальное мероприятие |
| **Влияние на квоту** | ❌ Не влияет |
| **Цель** | Подготовка к официальным соревнованиям |
| **Организатор** | Любая команда по желанию |
| **Обязанности организатора** | Место проведения, расписание, приглашение команд, элементы поля, компьютеры |
| **Собеседования** | По решению команды-организатора |

## 2. Региональные отборочные чемпионаты

| Параметр | Значение |
|----------|----------|
| **Статус** | Официальное соревнование |
| **Влияние на квоту** | ✅ Да — победители и призёры получают квоту |
| **Формат** | Очный (1–2 дня) или дистанционный |
| **Организатор** | Региональный ресурсный центр |
| **Количество матчей** | 5–6 зачётных квалификационных |
| **Уровень конкуренции** | Региональный |

## 3. Национальный чемпионат

| Параметр | Значение |
|----------|----------|
| **Статус** | Заключительный этап сезона |
| **Место** | г. Красноярск |
| **Длительность** | 3 дня |
| **Порог входа** | Квота с регионального отбора |
| **Организатор** | АНО «Лаборатория по робототехнике «Инженеры будущего»» |
| **Уровень конкуренции** | Всестрановой, высший |

## Сравнение форматов отборов

| | Очный отбор | Дистанционный отбор |
|---|-------------|---------------------|
| **Поле** | Полное официальное | Половина официального |
| **Подсчёт очков** | Только судьи | Судьи + команда |
| **Собеседование** | Очное | Видеоконференция или видео |
| **Инженерная книга** | Распечатанная версия | Электронный PDF-файл |
| **Матчей** | 5–6 | 6 |
