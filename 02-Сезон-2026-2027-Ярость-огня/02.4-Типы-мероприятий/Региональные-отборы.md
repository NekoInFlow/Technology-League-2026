# Региональные отборы

## Общие сведения

Региональные отборочные чемпионаты — это **официальные соревнования**, проводимые до Национального чемпионата для определения команд, которые получат квоту на следующий уровень.

## Организация

| Параметр | Значение |
|----------|----------|
| **Организатор** | Региональный ресурсный центр или назначенный им организатор |
| **Формат проведения** | Очный (1–2 дня) или дистанционный |
| **Площадка** | Должна размещать игровое поле и технические зоны |
| **Количество команд** | От 8 до 50 на очном мероприятии |

## Формат соревнований

### Очный формат
- Команды соревнуются друг с другом в Союзах на игровом поле
- Каждая команда играет **5–6 зачётных квалификационных матчей**
- Формируется рейтинг, по которому команды формируют Союзы для матчей на выбывание
- Союзы состоят из 2 или 3 команд (зависит от общего числа участников)
- Обязательное Собеседование с экспертами I этапа
- Для претендентов на номинации — углублённая оценка II этапа

### Дистанционный формат

Разработан для регионов без достаточного количества команд или при невозможности посетить очный чемпионат.

| Параметр | Значение |
|----------|----------|
| **Поле** | Половина официальной версии поля сезона |
| **Матчей** | 6 квалификационных |
| **Подсчёт очков** | Судьи + команда |
| **Собеседование** | Видеоконференция или заранее записанное видео |
| **Инженерная книга** | Электронный вид (PDF на облачном хранилище) |

## Продвижение

Количество квот определяется Положением конкретного этапа. При отсутствии иных указаний приоритет:

1. Абсолютный победитель
2. 2-е место абсолютного рейтинга
3. 3-е место абсолютного рейтинга
4. Победители обязательных экспертных номинаций
5. Далее — команды по итоговому абсолютному рейтингу
