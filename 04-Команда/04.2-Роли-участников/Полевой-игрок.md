# Полевой игрок

**Полевой игрок** — участник команды операторов, отвечающий за работу с Игровыми элементами во время Матча. Идентифицируется по бейджу «Полевой игрок».

## Обязанности

### В Управляемом периоде
- **Обмен Маяка:** замена Маяка своего Союза на дополнительные Игровые шары цвета своего Союза (ПС 7)
- Выкладывание дополнительных шаров в Зону парковки 1

### Ограничения поля (ПС 8)

| Правило | Описание |
|---------|----------|
| Только обмен маяка | Выкладывать шары можно только в рамках обмена маяка |
| Один шар за раз | Не более одного выложенного шара одновременно в Зоне парковки 1 |
| Робот не в зоне | Выкладывать шар только когда ни один робот Союза не находится в Зоне парковки 1 |
| Без вертикального пересечения | Не нарушать вертикальную плоскость периметра Игрового поля вне процедуры обмена |
| Никакой ручной передачи | Не передавать Игровой элемент роботу рукой вне обмена |

Каждое нарушение → Штраф.

## Важное правило

Только один Полевой игрок представляет весь Союз в Матче. Если в Союзе три команды — один Полевой игрок действует от имени всего Союза.
