# Дополнительные материалы

## Определение

**Дополнительные материалы** — общий документ, описывающий все этапы подготовки и работы команды в течение сезона. Включают постеры, видеоролики, презентации, зарисовки, обсуждения встреч, эволюцию дизайна Робота, процессы решённых проблем и мысли участников.

**Не являются обязательным** компонентом для присуждения номинаций, но могут быть приняты экспертами при необходимости дополнительной информации.

## Содержание

| Тип материала | Описание |
|---------------|----------|
| **Документация** | Зарисовки, обсуждения, встречи команд, эволюция дизайна Робота, решённые проблемы |
| **Агитационная работа** | Информация об агитации и сборах средств |
| **Планы команды** | Бизнес-планы, стратегии развития |
| **Дизайн Роботов** | Черновики концепций, прототипы |
| **Мысли участников** | Мнения каждого участника на протяжении пути |

## Формат

| Формат | Описание |
|--------|----------|
| **Электронный** | Электронные программы; один нередактируемый файл (PDF) в облачном хранилище (Яндекс.Диск) со ссылкой для экспертов |
| **Рукописной** | Рукописной текст, рисунки или чертежи от руки |
| **Смешанный** | Комбинация обоих форматов |

Эксперты не делают различий между форматами.

## Требования

| Правило | Описание |
|---------|----------|
| **Номер команды** | Настоятельно рекомендуется размещать на титульной странице |
| **Страница 2** | Рекомендуем одностраничное резюме, соединяющее информацию из Инженерной книги с соответствующими страницами Дополнительных материалов |
| **Очная оценка** | Распечатанная версия должна быть доступна в технической зоне команды |
| **Дистанционная** | Один PDF-файл с доступом по ссылке |
| **II этап собеседования** | Материалы могут использоваться экспертами во время второго интервью |

## Отличие от Инженерной книги

| Параметр | Инженерная книга | Дополнительные материалы |
|----------|------------------|---------------------------|
| Обязательность | ✅ Обязательно для каждой номинации | ❌ Не обязательно |
| Объём | ≤ 16 страниц | Без ограничений |
| Формат оценки | Все номинации | При изучении II этапа в Технической зоне |
| Ссылки | Только внутри книги | Ссылки на страницы книги разрешены |
