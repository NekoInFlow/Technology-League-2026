# Требования к Инженерной книге

## Определение

**Инженерная книга** — резюме команды: краткое и чёткое изложение всего объёма работы, выполненной за сезон. Включает чертежи, обсуждение, эволюцию дизайна, сложности при создании Робота, цели и планы по изучению навыков, результаты развития сообщества.

Для каждого нового сезона создаётся новая инженерная книга. Новый сезон начинается сразу после последнего мероприятия предыдущего.

## Обязательные компоненты

| Компонент | Описание |
|-----------|----------|
| Процесс проектирования/разработки | Чертежи, обсуждения, идеи мозгового штурма |
| Эволюция дизайна Робота | Улучшения конструкции, прототипирование |
| Сборка и тестирование | Описание сборки, испытаний, выводов |
| Командный план | Бизнес-план, стратегический план, план устойчивого развития |
| Деятельность по развитию сообщества | Популяризация Лиги, наставничество, привлечение |
| Продвижение | Распространение знаний и опыта |

## Форматы (ТИ 3)

| Формат | Описание |
|--------|----------|
| **Электронный** | Любые программы для создания; один нередактируемый файл (PDF) в облачном хранилище с доступом для экспертов |
| **Рукописный** | Полностью рукописной или частично с электронным текстом, чертежами от руки |
| **Смешанный** | Рукописной текст, рисунки + электронный текст |

Эксперты не делают различий между форматами.

## Ограничения (ТИ 4–6)

| Правило | Требование |
|---------|-----------|
| **ТИ 4: Объём** | Максимум **15 страниц** + титульная страница = **16 строк максимум**. Последующие страницы не рассматриваются |
| **ТИ 5: Номер команды** | Должен быть в верхней части первой страницы (обложки). Книга без номера → не рассматривается |
| **ТИ 6: Размер страниц** | Не более А4 (210×297 мм) |
| **ТИ 7: Шрифт** | Не менее 10 пт (высота буквы ≥ 2 мм при печати); избегать узких шрифтов |
| **ТИ 8: Внешние ссылки** | ❌ Никаких внешних ссылок на документы, веб-сайты или видео |
| **TI 1:** Претензия на номинации | Команда обязана предоставить Инженерную книгу |

## Титульная страница (ТИ 10)

Допускается: содержание, номер команды, название команды, местоположение, школа/организация, девиз, изображение Робота и/или команды. Никакая другая информация на первой странице экспертами не рассматривается.

Заявки на отдельные номинации **не входят** в общий объём книги.
