# Формат и содержание Инженерной книги

## Рекомендуемая структура

Инженерная книга может включать следующие разделы:

### 1. Техническая часть
| Элемент | Описание |
|---------|----------|
| Процессы проектирования/разработки | Обоснование инженерных решений, эскизы, черновики |
| Улучшение конструкции | История итераций дизайна Робота |
| Расчёты | Физические, математические расчёты, модели |
| Сборка | Описание процесса сборки ключевых узлов |
| Тестирование | Результаты тестов, выводы, доработки |
| Дефицит ресурсов | Описание бюджета, проблемы с закупками |

### 2. Командная информация
| Элемент | Описание |
|---------|----------|
| О команде | Участники, роли, состав |
| Развитие сообщества | Деятельность команды по популяризации Лиги |
| Взаимодействие с профессиональным сообществом | Наставники, эксперты, университеты, компании |

### 3. Командный план
| Элемент | Описание |
|---------|----------|
| Бизнес-план | Финансирование, сбор средств |
| Стратегический план | Цели на сезон, развитие навыков |
| План устойчивого развития | Долгосрочные цели команды |
| Привлечение новых участников | Работа с новыми членами команды |

## Рекомендации по наполнению

- **Не только успехи:** документация должна показывать не только успешные решения, но и выводы из неудачных вариантов
- **Чёткие аргументы:** для каждого ключевого решения рассмотреть варианты и привести инженерные обоснования
- **Доказательства:** зафиксировать испытания, результаты, выводы и причины изменений конструкции

## Ссылки на страницы в книге

Эксперты при оценке номинаций будут искать информацию на конкретных страницах. Рекомендуется составлять оглавление с навигацией по разделам и номерам страниц.
