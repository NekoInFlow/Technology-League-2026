# Порядок продвижения

## Приоритет предоставления квот

Если Положением не установлен иной порядок, приоритет определяется итогами абсолютного рейтинга и обязательных экспертных номинаций в следующей последовательности:

| Приоритет | Критерий |
|-----------|----------|
| 1 | Абсолютный победитель (1-е место АР) |
| 2 | 2-е место абсолютного рейтинга |
| 3 | 3-е место абсолютного рейтинга |
| 4–10 | Победители обязательных экспертных номинаций (в порядке приоритета номинаций) |
| Далее | Команды по итоговому абсолютному рейтингу |

## Порядок номинаций при распределении наград

| № | Номинация |
|---|----------|
| 1 | Инженерное решение |
| 2 | Продуманный подход |
| 3 | Программная инженерия |
| 4 | Развитие сообщества |
| 5 | Инновационный подход |
| 6 | Дизайн Робота |
| 7 | Взаимодействие |

Команда, уже получившая обязательную экспертную награду, пропускается — награда переходит к следующей Команде рейтинга, которая ещё не была награждена.

## Квоты на Национальный чемпионат

Количество квот устанавливается Положением конкретного этапа. Если Положением не установлен иной порядок — применяется указанный выше порядок.

По каждому направлению Соревнований к Заключительному этапу Чемпионата допускаются победители и призеры Отборочных этапов в соответствии с квотами. Для участия в Национальном чемпионате необходимо пройти Региональный отборочный чемпионат и получить квоту.
