# Квоты на Национальный чемпионат

## Общие принципы

| Параметр | Описание |
|----------|----------|
| **Организатор** | АНО «Инженеры будущего» и партнёры |
| **Место проведения** | г. Красноярск (площадка партнёра) |
| **Формат** | Очный, 3 дня |
| **Условие участия** | Пройти Региональный отбор и получить квоту |
| **Регистрация** | На сайте ncrobo.ru |

## Определение количества квот

Количество квот на Соревнования следующего уровня устанавливается Положением конкретного этапа. Если Положением не установлен иной порядок, приоритет предоставления квот определяется итогами абсолютного рейтинга и обязательных экспертных номинаций:

### Порядок выделения квот

1. Абсолютные победители региональных отборов
2. Победители обязательных экспертных номинаций (по приоритету)
3. Команды по лучшему абсоютному рейтингу

## Требования к команде для получения квоты

| Требование | Статус |
|-----------|--------|
| Участие в ≥5 зачётных квалификационных матчах | ✅ Обязательно |
| Технический допуск Робота | ✅ Обязательно |
| Собеседование с экспертами I этапа | ✅ Обязательно |
| Предоставление Инженерной книги | ✅ Обязательно |
| Регистрация на ncrobo.ru | ✅ Обязательно |

## Национальный чемпионат — отличия

- Более высокий уровень конкуренции как на поле, так и при определении Внеигровых достижений
- Премиальное задание в Игре роботов (если большинство команд достигли близких к максимальным результатов)
- Общий рейтинг команд на НЧ не публикуется
- Статус Абсолютного победителя присваивается только на Заключительном этапе
