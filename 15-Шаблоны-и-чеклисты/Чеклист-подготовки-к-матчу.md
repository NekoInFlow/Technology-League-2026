# Чеклист подготовки к матчу

**Союз:** ☐ Красный ☐ Синий | **Номер команды:** \_\_\_ | **Дата матча:** \_\_\_ | **Время:** \_\_\_

## Команда операторов (≤4 чел.)
- [ ] Все члены команды имеют бейджи («Оператор», «Полевой игрок», «Тренер»)
- [ ] 2 Оператора готовы управлять роботом
- [ ] Полевой игрок знает порядок обмена Маяка (ПС 7)
- [ ] Тренер знает зону Союза и правила ПИ 16

## Защита (средства безопасности)
- [ ] Все члены команды носят защитные очки внутри Соревновательной Зоны (ОТ 15, ПБ 3)
- [ ] Обувь с закрытым носком и закрытой пяткой (ОТ 17)
- [ ] Тонированные линзы разрешены только если персонал видит глаза

## Робот — предматчевая проверка
- [ ] Габариты в стартовом положении ≤ 45×45×45 см (ТР 4)
- [ ] Масса без ИЭ ≤ 15 кг (ТР 5)
- [ ] Номер команды виден с ≥2 противоположных сторон (синяя и красная таблички) (ТР 6)
- [ ] Главный выключатель обозначен наклейкой (ЭР 1)
- [ ] Предзагрузка: 1 белый шар + 1 цветной шар + Флаг Союза в каждом роботе
- [ ] Кнопка Запуска автономного периода функционирует (ЭР 16)

## Станция Управления
- [ ] Все устройства работают и подключены
- [ ] Беспроводное соединение установлено между устройствами Команды
- [ ] Проверен Wi-Fi канал (согласован с Организатором при необходимости, ОТ 13)
- [ ] Встроенные аккумуляторы заряжены / переносные зарядники готовы

## Программа Робота
- [ ] Автономная программа загружена и протестирована
- [ ] Переход из АП в УП работает корректно (ПР 1)
- [ ] Программы для обоих режимов выбраны на Станции Управления
- [ ] Тренировочные заезды выполнены

## Перед матчем (за 5 минут до начала)
- [ ] Капитан Союза уведомил судей о составе двух участвующих команд (≥2 мин до начала, Матчи на выбывание)
- [ ] Робот установлен у борта по схеме (§ 2.3.1): Красный → A5/A3/A2; Синий → F5/F4/F2
- [ ] После Рандомизации робот и станция не трогались (ПИ 21)
- [ ] Члены Команды операторов ожидают вызова в своей зоне Союза

## Во время матча
- [ ] Не покидать Зону Союза (ПИ 16)
- [ ] Не касаться поля/роботов во время матча (ПИ 23)
- [ ] Только Операторы управляют роботом (ПИ 24)
- [ ] Не использовать электронную связь во время матча (ПИ 11)
- [ ] Следить за лимитом: макс 2 шара одновременно (ПС 3)

## После матча
- [ ] Роботы прекратили движение в конце каждого периода (ПИ 20)
- [ ] Быстро убрать элементы и robot с поля (ПИ 17)
- [ ] Вернуть все ИЭ на поле по сигналу Судьи

## Если берёшь тайм-аут (только Матчи на выбывание)
- [ ] Тайм-аут запрошен ДО начала матча, до установки роботов противника (ОТ 10)
- [ ] Длительность ≤ 3 минут
