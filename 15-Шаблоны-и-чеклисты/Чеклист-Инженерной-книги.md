# Чеклист Инженерной книги

**Номер команды:** \_\_\_ | **Дата проверки:** \_\_\_

## Формат и ограничения
- [ ] Максимум 15 страниц контента + титульная страница = **≤ 16 страниц**
- [ ] Номер команды в верхней части первой страницы (обложки)
- [ ] Размер страниц не более А4 (210×297 мм)
- [ ] Шрифт не менее 10 пт (высота буквы ≥ 2 мм)
- [ ] Внешних ссылок на документы/сайты/видео — **НЕТ**
- [ ] Заявки на номинации НЕ входят в объём книги

## Титульная страница (только что указано ниже)
- [ ] Номер команды
- [ ] Название команды
- [ ] Местоположение / школа / организация
- [ ] Девиз команды
- [ ] Изображение Робота и/или команды
- [ ] Содержание (рекомендуется)
- [ ] Нет другой информации, не относящейся к списку выше

## Техническая часть (ИТК)

### Продуманный подход (ПП)
- [ ] Путь от игровой задачи → стратегии → требований → проектирования → конструкции
- [ ] Рассмотрены варианты решений с инженерными аргументами выбора
- [ ] Физические/математические расчёты, модели где уместно
- [ ] Испытания, результаты, выводы, причины итераций зафиксированы
- [ ] Непроработанные неудачные варианты тоже показаны

### Инженерное решение (ИР)
- [ ] Архитектура системы управления описана
- [ ] Разделение собственных решений от готовых компонентов
- [ ] Назначение Контроллеров, питание, связь, интерфейсы, диагностика объяснены
- [ ] Ключевые решения технически обоснованы
- [ ] Система реализована на Роботе, работоспособность показана
- [ ] Заполнена Заявка на номинацию «Инженерное решение» (приложение отдельно)

### Программная инженерия (ПИ)
- [ ] Структура ПО, датчики, ключевые алгоритмы описаны
- [ ] Автономные функции в АП / автоматизация в УП реализованы
- [ ] Инженерный подход к тестированию и отладке показан
- [ ] Программные функции работают и дают практический эффект
- [ ] Заполнена Заявка на номинацию «Программная инженерия» (приложение отдельно)

### Инновационный подход (ИП)
- [ ] Конкретное оригинальное решение чётко выделено и описано
- [ ] Отличие от распространённых подходов показано
- [ ] Путь разработки, варианты, прототипирование задокументированы
- [ ] Решение фактически реализовано и эффективно

### Дизайн Робота (ДР)
- [ ] Чертежи и/или модели в САПР ключевых узлов и общей конструкции
- [ ] Компоновка, конструктивные решения, способы изготовления обоснованы
- [ ] Робот выполнен аккуратно, узлы интегрированы и доступны для обслуживания
- [ ] Сочетание функциональности, эргономики и визуальной целостности

## Социальная часть (КСК)

### Развитие сообщества (РС)
- [ ] Системная деятельность популяризации Лиги описана
- [ ] Подтверждаемые результаты (новые участники, созданные команды, наставничество)
- [ ] Делится опытом, а не только достижениями
- [ ] Качество презентации и ответов на вопросы показано

### Взаимодействие (В)
- [ ] Цели развития знаний и навыков участников сформулированы
- [ ] Взаимодействие с наставниками, инженерами, вузами, компаниями
- [ ] Как полученные знания применены в Роботе
- [ ] Примеры улучшений на основе профессиональной обратной связи

## Игры роботов (ИГ)
- [ ] Инженерная книга содержит информацию о процессе создания Робота для Игры
- [ ] Эволюция дизайна за сезон показана
- [ ] Технические решения и их эффективность связаны с Игрой

## Общие требования
- [ ] Благородный Профессионализм отражён
- [ ] Самостоятельное участие детей подтверждено
- [ ] Каждую страницу удобно нумеровать (рекомендуется номер команды вверху)
- [ ] Оглавление с навигацией по разделам есть
- [ ] Номера страниц согласованы со ссылками в Заявках на номинации
