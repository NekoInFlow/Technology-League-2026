# Флаг Союза

Каждая команда готовит **один (1) Флаг** своего Союза перед каждым Матчем. Флаг — Игровой элемент команды, маркируется цветом Союза за который играет команда.

## Материалы (ФС 1)

| Ограничение | Описание |
|-------------|----------|
| **Материалы** | По разделу «Материалы Робота» (§ 6.3.2) |
| **Электроника** | ❌ Запрещена |
| **Источники питания** | ❌ Запрещены |
| **Игровые элементы сезона** | ❌ Запрещены |
| **Острые края** | ❌ Запрещены |
| **Повреждение поля** | ❌ Запрещено |

## Размеры (ФС 2)

| Параметр | Значение |
|----------|----------|
| **Максимум** | 20 × 20 × 20 см |
| **Форма** | Произвольная |

## Маркировка (ФС 3)

| Элемент | Требование |
|---------|------------|
| Номер команды | С двух сторон, только цифры, высота ≥2 см, толщина линии ≥0,3 см |
| Цвет Союза | Красно-синяя сменная маркировка с двух сторон |
| Минимальный цветовой блок | 8 × 5 см |
| Название/логотип команды | Допускаются |

Маркировка должна быть сменной — поворотной или иным способом для быстрой смены цвета между матчами без изготовления второго флага.

## Установка (ФС 4)

| Критерий | Описание |
|----------|----------|
| **Крепление** | На выбор команды |
| **Надёжность** | Флаг должен удерживаться роботом до момента установки |
| **Безопасность** | Возможность безопасно установить на Верхнюю перекладину Союза или Жёлтую перекладину Башни |
