# Запрещённые элементы

## Механизмы и детали (ТР 1)

| Категория | Примеры |
|-----------|---------|
| Повреждающие поле | Колеса повышенной проходимости, антибуксовочные протекторы |
| Повреждающие других роботов | Любые разрушающие механизмы |
| Опасные для людей | Острые края/углы; ртутные выключатели, свинец |
| Жидкие/газообразные | Гели, сыпучие материалы; пневматические устройства (компрессоры, газовые пружины); гидравлика; вакуумные механизмы |
| Здоровье | Материалы животного/растительного происхождения |
| Электрические | Элементы, заземляющие робота на поле |
| Запутывание | Риск запутывания вращающихся механизмов |

## Запуск частей (ТР 6)

❌ Преднамеренный запуск **любой части Робота** — даже если часть подключена тросом/проводом/верёвкой.

## Модификация электроники (ЭР 14)

❌ Внутренние изменения электроники — разрешены только механические модификации.

## Несколько роботов (ОТ 5)

- Один робот на соревнования (собранный для текущего сезона)
- Настройка запасного робота во время соревнований
- Использование робота другой команды

Нарушение = Грубое поведение → дисквалификация.

## Лазеры (ЭР 11)

❌ Лазеры и любые сфокусированные/направленные источники света, способные ослеплять участников, судей или мешать другим роботам.
