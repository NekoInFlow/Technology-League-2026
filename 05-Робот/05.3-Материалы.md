# Материалы

## Разрешённые материалы (МР 1)

Любые общедоступные материалы в первоначальном или изменённом виде:

| Тип | Примеры |
|-----|---------|
| Листовые материалы | Металл, пластик, дерево, резина, перфорированные/рифлёные листы |
| Пресованные формы | Металлопрокат, литые детали, детали литьём/давлением |
| Детали 3D-печати | Любые напечатанные элементы |
| Кабели и тросы | Шнуры, нити, канаты |
| Пружины | Сжатия, растяжения, кручения, медицинский жгут |

**Источники:** ЛЕМА ПРО (Леруа Мерлен), ОБИ, «Лига Технологий+», TETRIX/PITSCO, MATRIX/Modern Robotics, REV Robotics и др.

## Коммерческие нестандартные детали — КНД (МР 2)

Разрешены при условии **одной степени свободы**:

| Система | Описание |
|---------|----------|
| Линейный привод | Одно вращательное → одно поступательное движение |
| Шкив | Вращается вокруг одной оси |
| Односкоростной редуктор | Один вход → один выход |

Запрещены многокомпонентные системы с несколькими степенями свободы, поставляемые в собранном виде без возможности замены деталей.

## Изменение материалов (МР 3–5)

| Правило | Описание |
|---------|----------|
| **МР 3** | Материалы и КНД можно просверливать, разрезать, красить |
| **МР 4** | Сборка: сварка, пайка, склеивание, крепёж любого типа |
| **МР 5** | Смазка разрешена, если не загрязняет поле и роботов |
