# Программное обеспечение

## Переход из Автономного в Управляемый период (ПР 1)

Во время Технического допуска команда должна продемонстрировать переход от Автономного к Управляемому периоду на Станции Управления.

**Важно:** Переход не должен приводить к неконтролируемому движению Робота.

## Связь (ПР 2)

| Параметр | Значение |
|----------|----------|
| **Тип связи** | ТОЛЬКО беспроводная между Контроллер(ами) Робота и Станцией Управления |
| **Кому** | ТОЛЬКО устройствам своей команды |
| **Другие команды** | ❌ Запрещено подключаться к их устройствам или через их устройства |

## Беспроводные соединения (ОТ 12)

| Правило | Описание |
|---------|----------|
| **Запрет** | Установка собственного Wi-Fi/Bluetooth без необходимости для связи с роботом или загрузки программы |
| **Помехи** | Мешать коммуникации другой команды с её роботом запрещено |
| **Нарушение** | Дисквалификация с мероприятия |

### Wi-Fi канал чемпионата (ОТ 13)

Организатор может потребовать конкретный Wi-Fi канал или частоту. Отказ → жёлтая карточка.

## Режимы управления

**Режим управления** — программно-алгоритмический модуль, определяющий поведение Робота в заданный временной интервал. Активируется по команде или событию. Предоставляет Контроллеру:
- Обработку данных с Датчиков
- Решения по заложенной логике
- Управляющие воздействия на исполнительные механизмы
