# Аккумуляторы и питание

## Основной аккумулятор (ЭР 3)

| Параметр | Значение |
|----------|----------|
| **Количество** | ОДИН силовой |
| **Назначение** | Питание всех приводов (моторы, сервоприводы, исполнительные механизмы) |
| **Максимальное напряжение** | ≤15 В в любой точке цепи |
| **Дополнительный аккумулятор к приводам** | ❌ Запрещено |

## Дополнительный аккумулятор (ЭР 4)

| Параметр | Значение |
|----------|----------|
| **Назначение** | Контроллеры, датчики, камеры, освещение, низкопотребляющие устройства |
| **Количество** | Не ограничено |
| **Тип** | Немодифицированные серийные источники |
| **Крепление** | Надёжно закреплены |
| **Показаны на допуске?** | ✅ Да |
| **Отключаются Главным выключателем?** | ✅ Да |
| **Можно питать моторы/серво?** | ❌ Нет |

## Требования к аккумуляторам (ЭР 2)

### Крепление
- Текстильная застежка, кабельная стяжка или резинка
- Не контактирует с другими роботами или полем
- Изолирован от острых краёв (головки винтов, резьба)

### Типы батарей

| Тип | Требования |
|-----|-----------|
| Любые немодифицированные серийные | Подключены заводским способом |
| Li-ion / Li-Po / Li-Fe | BMS + зарядное устройство + огнестойкий мешок при транспортировке |
| LEGO Mindstorms / ноутбук / телефон | Только внутри устройства, по назначению производителя |

### Огнестойкий мешок
Батареи Li-Po/Li-ion должны **постоянно находится в сертифицированном огнеупорном контейнере** на протяжении всего периода соревнований и при транспортировке.

## Предохранители (ЭР 5)

| Параметр | Значение |
|----------|----------|
| **Номинал** | 20 А или меньше на положительном проводе |
| **Тип** | Одноразовый; автоматические запрещены |
| **Сменные** | Только одноразового использования |
| **Проверка** | В любой момент времени; повторное нарушение → дисквалификация |

## Разрешённые источники энергии (ТР 5)

1. Электрическая энергия аккумуляторов
2. Изменение положения центра тяжести робота
3. Накопленная энергия за счёт деформации деталей (пружинные механизмы с большой осторожностью)
