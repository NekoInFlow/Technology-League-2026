# Станция Управления

**Станция Управления** — аппаратно-программный комплекс из одного или нескольких устройств для подготовки, запуска и беспроводного управления роботом.

## Состав станции (ЭР 15)

| Устройство | Примеры |
|------------|---------|
| Компьютер | Ноутбук, десктоп |
| Мобильное устройство | Телефон, планшет |
| Встроенные системы | Микроконтроллер, одноплатный компьютер |

### Допустимые связки
- Телефон + компьютер
- Компьютер + микроконтроллер
- Одноплатный компьютер + микроконтроллер
- Любые аналогичные архитектуры

## Правила размещения

| Правило | Описание |
|---------|----------|
| **Зона Союза** | Все устройства до конца Матча находятся в Зоне Союза |
| **Управление** | Только членами команды операторов |
| **Соединение между устройствами** | Проводное или беспроводное |
| **Питание на матче** | От встроенных аккумуляторов устройств и/или коммерческих переносных аккумуляторов |
| **Сеть во время матча** | ❌ Подключение к стационарной электросети запрещено |

## Органы управления

| Тип | Примеры |
|-----|---------|
| Геймпады | Игровые контроллеры |
| Джойстики | Ручные манипуляторы |
| Клавиатуры / мыши | Стандартные ПК-устройства |
| Сенсорные экраны | Планшеты, телефоны |

Все используемые органы управления должны быть представлены на Техническом допуске.

## Беспроводная связь (ПР 2)

| Параметр | Значение |
|----------|----------|
| **Тип связи** | ТОЛЬКО беспроводная между Контроллер(ами) Робота и Станцией Управления |
| **Кому** | ТОЛЬКО устройствам своей команды |
| **Другие команды** | ❌ Запрещено подключаться к их устройствам |
| **Новые соединения** | ❌ Запрещено устанавливать Wi-Fi/Bluetooth без необходимости |

## Кнопка Запуска (ЭР 16)

Каждая команда, планирующая использовать Автономный период, должна иметь одну Кнопку Запуска.

| Параметр | Значение |
|----------|----------|
| **Местоположение** | Только на Станции Управления; видна Судьям |
| **Размер** | ≥1×1 см ±0,1 см |
| **Цвет заполнения** | Чёрный (можно заменить) |
| **Наклейка** | «КНОПКА ПИТАНИЯ» на плоской поверхности ≥2×6 см возле Главного выключателя робота |

### Назначение кнопки

Нажатие = запуск автономной программы. Во время Автономного периода единственное разрешённое взаимодействие с командой оператора.
