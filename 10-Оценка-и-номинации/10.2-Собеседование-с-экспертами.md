# Собеседование с экспертами

## Общая структура

| Параметр | I этап (обязательный) | II этап (по номинациям) |
|----------|----------------------|------------------------|
| **Где проходит** | Комната экспертов | Техническая зона команды |
| **Для кого** | Все команды | Только Команды-претенденты |
| **Формат** | Защита + вопросы | Углублённое сравнение по номинации |
| **Время** | ≤ 5 мин презентация + вопросы | По предварительной договорённости |
| **Эксперты** | Группа из 3–4 человек | Специализированная группа по номинации |
| **Источники** | Инженерная книга, Робот, Заявка | Инженерная книга, Заявки, наблюдение на поле |
| **Тренер в комнате** | Может присутствовать как зритель | Может наблюдать, не отвечает за участников |
| **Запись** | ❌ Запрещена | ❌ Запрещена |

## Расписание

- Команды обязаны проходить I этап согласно официальному расписанию
- Расписание имеет приоритет над Техническим допуском и тренировками
- Матчи и подготовка к ним имеют приоритет над доп. общением II этапа

## Что оценивается

### Презентация (до 5 минут)
Команда представляет: Робота, Инженерную книгу, необходимые Заявки; проводит презентацию и отвечает на вопросы.

### Вопросы экспертов о:
- Компании и распределении ролей
- Роботе и технических решениях
- Программировании и системах управления
- Деятельности по развитию сообщества
- Использовании Инженерной книги
- Принципах Благородного Профессионализма

## Номинация во II этап

Камера экспертов принимает решение по каждой номинации отдельно:

| Условие | Требуется |
|---------|-----------|
| Ни по одному критерию | ❌ Не «Начальный» |
| Хотя бы по одному критерию | ✅ «Развивающийся» |

Нет ограничений по количеству номинированных команд от одной комнаты.

## Что демонстрировать

| Для номинации | Что показать |
|---------------|-------------|
| Инженерное решение | Систему управления, архитектуру контроллеров, питание, связь |
| Продуманный подход | Историю проектирования, варианты решений, расчёты |
| Программная инженерия | Алгоритмы автономного/управляемого периодов, датчики |
| Инновационный подход | Оригинальные механизмы и их преимущества |
| Дизайн робота | Чертежи, САПР, качество сборки |
| Развитие сообщества | Системную деятельность популяризации |
| Взаимодействие | Работа с наставниками, компаниями, вузами |
