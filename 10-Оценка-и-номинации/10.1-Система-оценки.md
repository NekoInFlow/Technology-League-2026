# Система оценки

## Двухуровневая система оценивания

Экспертная оценка проводится в два этапа и использует три источника: собеседование с командой, наблюдение за работой Робота, Инженерная книга.

### I этап — Защита в комнате экспертов

| Параметр | Значение |
|----------|----------|
| Формат | Команда выступает перед группой из 3–4 экспертов |
| Презентация | До 5 минут самостоятельной презентации |
| Вопросы | О команде, Роботе, программировании, инженерных решениях, деятельности в сообществе |
| Инженерная книга | Один из источников информации; подробное изучение не требуется |
| Доступные уровни | Начальный (0 баллов), Базовый (3 балла), Развивающийся (5 баллов) |

**Уровень «Развивающийся»** означает, что команда демонстрирует основания претендовать на уровень «Сформированный» при углублённой оценке.

### II этап — Углублённая оценка

| Параметр | Значение |
|----------|----------|
| Формат | Специализированные группы по конкретным номинациям |
| Кого оценивают | Только Команды-претенденты |
| Где проходят | Техническая зона команды |
| Изучают | Инженерная книга, Заявки, наблюдают Робота на поле |
| Доступные уровни | Базовый (3), Развивающийся (5), Сформированный (7), Превосходный (10) |

### Критерии допуска во II этап

Обязательное условие: **ни по одному критерию номинации не выставлен «Начальный»** и хотя бы по одному критерию выставлен **«Развивающийся»**. Ограничений по количеству номинированных команд нет — могут быть номинированы все, несколько или ни одной.

### Итоговое ранжирование

1. Команды, прошедшие во II этап → выше всех в рейтинге номинации
2. Команды, не прошедшие во II этап → ранжируются по сумме баллов I этапа
3. Электронная система объединяет результаты I и II этапов и формирует рейтинговый список

## Абсолютный рейтинг (АР)

Формируется из трёх равноправных направлений — каждое составляет **1/3** итогового результата:

$$АР = (ИТК + КСК + ИГ) / 3$$

| Направление | Доля | Компоненты |
|-------------|------|-----------|
| **Инженерно-технические компетенции (ИТК)** | 1/3 | Продуманный подход + Инженерное решение + Инновационный подход + Программная инженерия + Дизайн Робота |
| **Командные и социальные компетенции (КСК)** | 1/3 | Взаимодействие + Развитие сообщества |
| **Игры роботов (ИГ)** | 1/3 | Итоговое место в Играх роботов + рейтинговое место по средним ИБ |

Чем меньше значение АР — тем выше команда в рейтинге.

## Пример расчёта

ИТК = 2,00; КСК = 2,00; ИГ = 1,50

$$АР = (2,00 + 2,00 + 1,50) / 3 = 1,83$$

При равенстве АР преимущество последовательно получает Команда с меньшим ИТК, затем с меньшим ИГ, затем с меньшим КСК, затем более высоким местом в КМ, затем случайный электронный выбор.
