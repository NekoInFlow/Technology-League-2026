# Абсолютный победитель

## Расчёт абсолютного рейтинга (АР)

Команда с наименьшим значением АР занимает 1-е место и получает номинацию «Абсолютный победитель Лиги «Технологий»».

$$АР = (ИТК + КСК + ИГ) / 3$$

### Компоненты

| Компонент | Формула | Описание |
|-----------|---------|----------|
| **ИТК** | (ИР + ПП + ИП + ПИ + ДР) / 5 | Среднее рейтинговых мест по инженерным номинациям |
| **КСК** | (В + РС) / 2 | Среднее рейтинговых мест по социальным номинациям |
| **ИГ** | (ИМ + РИБ) / 2 | Среднее места в Играх роботов и по средним ИБ |

### Пример расчёта

ИТК = 2,00; КСК = 2,00; ИГ = 1,50 → АР = 1,83

## Правила сравнения

- Команды с меньшим значением АР получают более высокое место
- Значения ИТК, КСК, ИГ и АР округляются до двух знаков после запятой только для публикации; при сравнении — неокруглённые значения
- При равенстве АР преимущество последовательно получает команда:
  1. С меньшим ИТК
  2. С меньшим ИГ
  3. С меньшим КСК
  4. Занимающая более высокое место в КМ
  5. Случайный электронный выбор

## Участие в абсолютном рейтинге

В АР участвуют команды, прошедшие: регистрацию, Технический допуск, представившие Инженерную книгу, прошедшие обязательное Собеседование и получившие действительные результаты в «Играх роботов». Дисквалифицированная команда исключается из АР.

## Публикация результатов

Организатор публикует итоговые значения ИТК, КСК, ИМ, СИБ, РИБ, ИГ и АР. Детальные оценки отдельных экспертов не публикуются. Команде может быть предоставлена обратная связь по итогам соревнований.
