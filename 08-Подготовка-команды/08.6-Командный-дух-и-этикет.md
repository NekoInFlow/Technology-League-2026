# Командный дух и этикет

## Командный стиль и бренд

| Элемент | Описание |
|---------|----------|
| **Название команды** | Подумайте как подать выгодно — для узнаваемости и привлекательности |
| **Футболки/бейсболки/костюмы** | Придумывайте свой стиль! Это приятная часть командной работы |
| **Техническая зона** | Оформляйте в уникальной стилистике команды |

## Баннеры и флаги

| Правило | Описание |
|---------|----------|
| **Местоположение** | Размещайте баннеры в технических зонах команд |
| **Спонсоры** | Спонсоры обеспечивают Организаторов баннерами; рекомендуется принести флаги спонсоров |
| **Запрещено** | Использовать баннеры или флаги для резервации мест на трибуне |

## Этикет поведения болельщиков

| Правило | Описание |
|---------|----------|
| **Допустимое количество зрителей у поля** | 2 Оператора + 1 Полевой игрок + 1 Тренер |
| **Зрители в Соревновательной Зоне** | ❌ Не допускаются |
| **Медиазона** | Доступ только со специального разрешения и только когда команда находится у поля |
| **Блокировка проходов** | Попросят переместиться; повторное нарушение = Грубое поведение |
| **Резервация мест** | Не забаривать сидения заранее (места могут не хватить) |

## Запреты на мероприятии

| Категория | Запрещено |
|-----------|-----------|
| **Перемещение** | Бегать, кататься на скейтбордах/роликах/гироскутерах, использовать дроны |
| **Шум** | Живая музыка на трибунах, громкая музыка, свистки, гудки горном |
| **Оружие** | Радиоприёмники и рации |
| **Пайка/инструменты** | Большая пайка, электроинструменты с искрами (только с разрешения Организатора) |
| **Продажа** | Сбор средств, продажа сувениров (кроме благотворительного сбора с согласия Организатора) |
| **Краска/спреи** | Краска, вредные продукты, спреи (антистатик — за пределами площадки) |
| **Конструкции зоны** | Более 3×3 м (или установленных организаторами размеров); хранить только в своей зоне |
| **Еда** | Организаторы вправе запретить проносить еду в Техническую и Соревновательную зоны |
