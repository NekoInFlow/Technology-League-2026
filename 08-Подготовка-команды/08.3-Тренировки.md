# Тренировки

## Общие правила

| Правило | Описание |
|---------|----------|
| **Тренировочные поля** | Предоставляются на крупных мероприятиях для практики команд |
| **Запись** | По очереди при помощи полевого волонтёра |
| **Ограничение времени** | Команда покидает тренировочное поле сразу по окончании отведённого времени |
| **Превью матча** | По предварительной записи в зоне тренировочных полей |

## Правила использования

- Привозить и располагать на площадке соревнований **собственные игровые поля строго запрещено!**
- Только зона тренировочных полей разрешена для тренировки между КМ
- Команды обязаны соблюдать порядок и не задерживаться после отведённого времени
- На крупных мероприятиях команды могут пользоваться полем для тренировок на протяжении всего Чемпионата

## Остановленный матч (ПИ 7)

Команда вправе попросить Судью **Отключить Робота**, если сбой алгоритмов может привести к неисправности. Отключённый робот не набирает баллов до конца Матча и не зарабатывает Штрафы после объявления.

## Перерыв между матчами (ОТ 8)

Команды, играющие в двух Матчах подряд, получают перерыв **не менее 5 минут** между сигналом восстановления поля и momentом установки роботов.
