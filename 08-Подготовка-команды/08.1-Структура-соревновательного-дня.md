# Структура соревновательного дня

## Этапы мероприятия

Команды на мероприятии Лиги «Технологий» проходят через следующие последовательные этапы:

| # | Этап | Описание |
|---|------|----------|
| 1 | **Регистрация Команд** | Сдача документов, получение расписания |
| 2 | **Технический допуск Робота** | Проверка соответствия всем требованиям |
| 3 | **Собеседование с экспертами** | I этап обязателен для всех; II этап по номинациям |
| 4 | **Собрание операторов** | Инструктаж от главного судьи перед КМ |
| 5 | **Церемония открытия** | Официальный старт соревнований |
| 6 | **Квалификационные матчи** | 5–6 зачётных Матчей для определения рейтинга |
| 7 | **Выбор Союзов** | Формирование Союзов из 2–3 команд |
| 8 | **Матчи на Выбывание** | Полуфиналы и финал (до двух побед) |
| 9 | **Награждение и закрытие** | Объявление финалистов и победителей в каждой номинации |

## Расписание

- Организаторы предоставляют расписание заранее или непосредственно на мероприятии
- Расписание Квалификационных Матчей составляется после регистрации и технических допусков всех команд
- Расписание имеет приоритет над Техническим допуском и тренировками
- **Расписание может изменяться** в течение мероприятия!

## Типы мероприятий

| Тип | Длительность | Особенности |
|-----|-------------|-------------|
| Товарищеская встреча | 1 день | Не влияет на квоты; без обязательных собеседований |
| Региональный отбор | 1–2 дня | Собеседования, КМ, выбор Союзов |
| Национальный чемпионат | 3 дня | Более высокий уровень конкуренции |

## Зоны площадки

| Зона | Назначение |
|------|-----------|
| Соревновательная зона | Игровые поля, Станции Союзов, судейские столы |
| Техническая зона | Работа над роботами между матчами (стол + питание) |
| Тренировочные поля | Практика; по предварительной записи |
| Комнаты экспертов | Собеседования с командой |
