# Выбор Союзов

## Общие положения

| Параметр | Значение |
|----------|----------|
| **Количество Союзов** | 4 Союза участвуют в Матчах на выбывание |
| **Состав Союза (≤20 команд)** | 2 Команды |
| **Состав Союза (>20 команд)** | 3 Команды |
| **Капитан Союза** | Команда с самым высоким рейтингом внутри Союза |

## Процедура

### Этапы выбора

1. Четыре лучшие команды по результатам Квалификации выходят первыми
2. Капитан #1 выходит вперёд и приглашает любую свободную Команду
3. Если команда принимает — становится участником Союза; если отказывается → её больше НЕ МОГУТ пригласить в другой Союз
4. Капитан переадресует приглашение другой команде
5. Выбранная команда выбирает себе партнёров из оставшихся свободных
6. Процесс продолжается пока все 4 Союза не заполнены

### При >20 командах (Союзы по 3)

После выбора капитанов проводится **«3-ий выбор Союза»** по принципу от высшего рейтинга к низшему (1→2→3→4). Команды, которые не были выбраны, **не участвуют** в Матчах на выбывание.

## Правила процедуры

| Правило | Описание |
|---------|----------|
| Представитель | Каждая команда выбирает одного представителя для участия в процедуре |
| Связь с командой | Допускается телефонная связь для консультации с участниками |
| Поведение | Вежливость, внимательность к другим, без задержек процедуры |

## Когда проводится

После завершения всех Квалификационных Матчей и формирования рейтинговой таблицы.
