# Глоссарий

## Игровой процесс

| Термин | Определение |
|--------|------------|
| **Автономный период** | Начальный 60-секундный период Матча, роботы выполняются миссии по заранее запрограммированным алгоритмам без вмешательства человека |
| **Управляемый период** | Двухминутный период Матча, во время которого Операторы управляют Роботами через Станцию Управления |
| **Заключительный период** | Последние 30 секунд Управляемого периода; доступны установка флагов и парковка на Башне |
| **Союз** | Каждый Матч состоит из двух Союзов (Красный и Синий) по две Команды каждая |
| **Матч** | Соревнование между двумя Союзами общей продолжительностью 3 минуты |
| **Квалификационный матч** | Матч для ранжирования Команд по рейтингу и определения претендентов на матчи на выбывание |
| **Матчи на выбывание** | Серия матчей до двух побед, определяющая Союз-Победителя и Союз-Финалиста |
| **Выбор Союза** | Процедура формирования Союзов из команд с высшим рейтингом |

## Элементы поля

| Термин | Определение |
|--------|------------|
| **Игровое поле** | Квадрат 3,6×3,6 м с бортом 30 см и мягкими плитками |
| **Башня** | Центральная конструкция с нижним и верхним уровнями, боковыми Наклонными плоскостями и перекладинами |
| **Склад** | Зона хранения Игровых элементов в противоположных углах поля |
| **Зона парковки** | Обозначенная цветом Союза область; целевая зона определяется Рандомизацией |
| **Игровой шар** | Шар диаметром 42 мм: белый, синий или красный |
| **Пластина** | Жёлтая или Белая пластина, закреплённая Зажимами на Башне |
| **Маяк** | Крестовина красного или синего цвета; захватывается в Автономном периоде |
| **Флаг Союза** | Игровой элемент Команды (≤20×20×20 см), устанавливается на перекладину Башни |
| **Рандомизация** | Случайный выбор целевой Зоны парковки (1, 2 или 3) перед матчем |

## Команда и роли

| Термин | Определение |
|--------|------------|
| **Команда** | От 2 до 8 участников + неограниченное число Наставников и максимум 2 Тренера |
| **Команда операторов** | До 4 представителей: 2 Оператора + 1 Полевой игрок + 1 Тренер команды операторов |
| **Оператор** | Участник, управляющий Роботом через пульт управления |
| **Полевой игрок** | Участник, отвечающий за работу с Игровыми элементами (обмен Маяка) |
| **Тренер** | Взрослый (>18 лет), сопровождающий команду и отвечающий за безопасность |
| **Наставник** | Взрослый специалист, помогающий команде технически; количество не ограничено |
| **Станция Управления** | Аппаратно-программный комплекс для запуска и беспроводного управления Роботом |

## Оценивание

| Термин | Определение |
|--------|------------|
| **Абсолютный рейтинг (АР)** | АР = (ИТК + КСК + ИГ) / 3; чем меньше — тем выше место |
| **ИТК** | Инженерно-технические компетенции: среднее по 5 техническим номинациям |
| **КСК** | Командные и социальные компетенции: среднее по Взаимодействию и Развитию сообщества |
| **ИГ** | Игры роботов: среднее от ИМ и РИБ |
| **ИБ** | Индивидуальные баллы — баллы за действия конкретного робота |
| **РБ** | Рейтинговые баллы — сумма баллов Союзов команды за все КМ |
| **ДБ1** | Дополнительные баллы — сумма баллов Автономного периода |
| **ДБ2** | Дополнительные баллы — сумма баллов Заключительного периода |

## Нарушения

| Термин | Определение |
|--------|------------|
| **Штраф** | +10 баллов сопернику за нарушение правил |
| **Двойной Штраф** | +20 баллов сопернику за тяжёлые нарушения |
| **Жёлтая карточка** | Предупреждение за грубое поведение |
| **Красная карточка** | Дисквалификация из Матча (= 2 жёлтых карточки); обнуляет результат матча |
| **Дисквалификация** | Исключение команды с соревнований |
| **Отключённый Робот** | Робот, выключенный из игры до конца Матча по требованию Судьи или Команды |
| **Блокировка** | Перекрытие всех путей движения к объекту/зоне ≥5 секунд |
